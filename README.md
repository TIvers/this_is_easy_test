# speedtest.py — замер скорости скачивания

Консольный скрипт на Python 3.9+, без сторонних зависимостей (только стандартная библиотека).

## Запуск

```bash
python3 speedtest.py <URL>
python3 speedtest.py https://example.com/big-image.jpg
```

Необязательные параметры:

| Параметр | Описание | По умолчанию |
|---|---|---|
| `-n`, `--requests` | количество запросов | 10 |
| `-t`, `--timeout` | таймаут сетевых операций, с | 30 |

## Что делает

1. Делает 10 запросов к указанному адресу **строго последовательно**, каждый раз дожидаясь полной загрузки тела ответа.
2. Для каждого запроса замеряет время (`time.perf_counter`) от начала запроса до получения последнего байта. Время включает установку соединения, TLS и заголовки.
3. Считает:
   - **среднее время запроса** = сумма времён / число успешных запросов;
   - **общий объём** — сумма размеров тел ответов;
   - **скорость скачивания** = общий объём / суммарное время запросов.
4. Печатает результаты по каждому запросу и итоги.

## Единицы измерения

- **Скорость — Мбит/с** (мегабиты в секунду): так провайдеры указывают скорость тарифов, поэтому результат легко сравнить. Дополнительно в скобках выводится **МБ/с** (мегабайты в секунду).
- Используются десятичные приставки: 1 МБ = 1 000 000 байт, 1 Мбит = 1 000 000 бит, 1 байт = 8 бит. Поэтому `Мбит/с = МБ/с × 8`.
- **Время — секунды**, объём — **МБ**.

## Пример вывода

```
Адрес: https://example.com/big-image.jpg
Запросов: 10

  [ 1/10]     5.20 МБ за  1.040 с  (  40.00 Мбит/с)
  ...

Итоги
  Успешных запросов:    10 из 10
  Среднее время запроса: 1.050 с
  Скачано всего:         52.00 МБ
  Скорость скачивания:   39.62 Мбит/с (4.95 МБ/с)
```

## Замечания

- Скорость считается как общий объём ÷ общее время, а не как среднее арифметическое скоростей отдельных запросов — так крупные ответы корректно весят больше.
- Запрашивается ответ без сжатия (`Accept-Encoding: identity`) и с `Cache-Control: no-cache`, чтобы объём соответствовал реально переданным данным, а кэш не искажал замер.
- Неудачные запросы (ошибка сети, таймаут, HTTP-ошибка) выводятся в консоль и в статистику не входят. Код возврата: `0` — все запросы успешны, `2` — часть неудачна, `1` — все неудачны.
- Результат зависит не только от вашего канала, но и от сервера и расстояния до него. Для честного замера берите файл от 5 МБ и выше на быстром CDN.
